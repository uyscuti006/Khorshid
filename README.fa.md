## تفاوت با v2rayNG

- صفحه‌ی اصلی یک دکمه‌ی اتصال است، نه فهرست سرور
- اشتراک‌ها را خودش دریافت می‌کند و سریع‌ترین سرور را خودکار انتخاب می‌کند
- برای استفاده‌ی روزمره نیازی به انتخاب دستی سرور نیست
- تنظیمات پیشرفته دست‌نخورده مانده، فقط از صفحه‌ی اصلی جابه‌جا شده
- همان پروتکل‌ها، همان هسته‌ی v2ray، چیزی حذف نشده
