# خورشید (Khorshid)

یک کلاینت V2ray برای اندروید، بر پایه‌ی [V2rayNG](https://github.com/2dust/v2rayNG) — با قابلیت‌های اضافه‌شده برای اتصال پایدارتر و امن‌تر.
---

## امکانات کلیدی

- **کاربری ساده** — رابط کاربری ساده و کاربرپسند برای مدیریت و اتصال سریع‌تر به کانفیگ‌ها
- **لیست کانفیگ‌های به‌روز** — دریافت و به‌روزرسانی خودکار کانفیگ‌ها
- **اسکنر IP تمیز** — پیدا کردن بهترین IPهای کلادفلر برای هر کانفیگ، بر اساس تأخیر، جیتر و سرعت
- **ساخت خودکار کانفیگ با IP تمیز** — تولید خودکار کانفیگ‌ها با IPهای تمیز پیدا‌شده

### کدام نسخه را نصب کنم؟

| نسخه | مناسب برای |
|---|---|
| `universal` | همه‌ی گوشی‌ها |
| `arm64-v8a` | اکثر گوشی‌های امروزی |
| `armeabi-v7a` | گوشی‌های قدیمی‌تر |
| `x86` / `x86_64` | شبیه‌سازها و برخی تبلت‌ها |

اگر از معماری گوشی خود مطمئن نیستید، نسخه‌ی `universal` را نصب کنید.
