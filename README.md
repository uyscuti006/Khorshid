# 🦁☀️ Khorshid

**A lightweight Android client for V2Ray, based on v2rayNG**

</div>

---

## Difference to v2rayNG

- Main screen is a single connect button, not a server list
- Fetches your subscriptions on its own and picks the fastest server automatically
- No manual server selection needed for everyday use
- Advanced settings are unchanged, just moved off the main screen
- same protocols, same v2ray core, nothing removed

## Download

Grab the latest APK from the **[Releases](https://github.com/uyscuti006/Khorshid/releases/latest)** page.

Not sure which file to pick?

| File | Use case |
|---|---|
| `Khorshid_x.x.x_arm64-v8a.apk` | Most modern phones (recommended) |
| `Khorshid_x.x.x_armeabi-v7a.apk` | Older/budget devices |
| `Khorshid_x.x.x_universal.apk` | Works on any device, larger file size |
| `Khorshid_x.x.x_x86` / `x86_64.apk` | Emulators, some tablets/Chromebooks |
