## ✨ Features

| | |
|---|---|
| 🎯 **One-Tap Connect** | Open the app, tap once, done. No server list to dig through. |
| ⚡ **Auto-Fastest Server** | Automatically fetches your subscriptions and connects to the lowest-latency server. |
| 🎨 **Minimalist UI** | Clean, distraction-free simple mode — with full v2rayNG power still available under advanced settings. |
| 🦁☀️ **Lion & Sun Visuals** | A distinct look and feel, not just a re-skin. |
| 🔒 **Privacy-Focused** | 100% open-source, built on the trusted v2rayNG core. |

## 📥 Download

Grab the latest APK from the **[Releases](https://github.com/uyscuti006/Khorshid/releases/latest)** page.

Not sure which file to pick?

| File | Use case |
|---|---|
| `Khorshid_x.x.x_arm64-v8a.apk` | ✅ Most modern phones (recommended) |
| `Khorshid_x.x.x_armeabi-v7a.apk` | Older/budget devices |
| `Khorshid_x.x.x_universal.apk` | Works on any device, larger file size |
| `Khorshid_x.x.x_x86` / `x86_64.apk` | Emulators, some tablets/Chromebooks |
