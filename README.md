# ☀️ Khorshid (خورشید)

Khorshid is a lightweight, modern, and minimalist V2Ray client for Android based on v2rayNG.

## ✨ Features
* 🎨 **Minimalist UI:** Clean interface with a dedicated simple mode.
* 🦁 **Lion & Sun Visuals:** Unique design featuring animated elements.
* ⚡ **High Performance:** Built on top of the robust v2rayNG core.
* 🔒 **Privacy Focused:** Completely open-source.
